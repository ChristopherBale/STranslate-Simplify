# 精简版

本分支以日常划词翻译为主，保留偶尔使用的截图翻译。

## 使用流程

- 首次启动默认启用划词悬浮图标：选中文字后显示小图标，点击图标才取词并自动翻译。
- 划词后立即翻译默认关闭，避免每次选择文字都弹出翻译结果。
- 截图翻译保留，默认快捷键为 `Alt + S`，使用已启用的 OCR 服务识别后翻译。
- 翻译和 OCR 引擎、语言选择、结果复制、历史记录及其余原有功能继续保留。

已有配置中的划词开关和快捷键优先于新默认值。如需改为悬浮图标模式，请在设置中关闭“鼠标划词直接翻译”，开启“划词后悬浮图标”。首次使用先配置至少一个自动执行的翻译服务；截图翻译还需要启用一个 OCR 服务。

## 已移除的功能

- 生词本设置页、输入区收藏按钮、译文附笔记收藏按钮和生词本快捷键。
- 语音合成设置页、原文与译文朗读、词典发音按钮、OCR 和图片翻译窗口朗读、静默 TTS 快捷键及外部调用。
- 主窗口快捷服务菜单中的生词本与 TTS 服务。
- 插件管理中的生词本与 TTS 分类、统计，以及这两类插件的市场查询。
- 默认解决方案中的 Edge TTS、欧路生词本插件构建项目。

主程序仅加载翻译、词典和 OCR 插件。旧版 TTS、生词本配置字段和插件 SDK 接口保留用于兼容；旧插件文件不主动删除，旧服务不会在启动时实例化。对应插件源码仍保留在仓库中，但不参与默认构建。

## 下载便携试用包

`simplify` 分支每次推送后，会运行 `Simplified Windows preview` 工作流，在 Windows 上构建并执行自动化测试。

1. 登录 GitHub，打开本仓库的 **Actions** 页面。
2. 选择 `Simplified Windows preview`，打开对应提交的运行记录。
3. 在页面底部 **Artifacts** 下载 `STranslate-Simplify-win-x64-preview`。
4. 解压下载文件，再解压其中的便携 ZIP，将整个程序目录放到独立位置。
5. 保留随包提供的空 `PortableConfig` 文件夹，退出原版后运行 `STranslate.exe`。

运行需要 .NET 10 Desktop Runtime，无需安装开发 SDK。构建产物保留 14 天；如测试失败，工作流仍会在编译成功后提供预览包，试用前请查看运行记录中的测试结果。主分支仍保留完整版。

## 在 Windows 上验证

需要 Windows 和 .NET 10 SDK。在仓库根目录执行：

```powershell
dotnet build src/STranslate.slnx --configuration Debug
dotnet test src/Tests/STranslate.Tests/STranslate.Tests.csproj --configuration Debug
dotnet run --project src/STranslate/STranslate.csproj
```

如需与原版隔离试用，在独立的构建输出目录内新建 `PortableConfig` 文件夹，然后退出原版并启动精简版。这样使用独立的配置和历史记录，原版安装目录也无需覆盖。此分支仍沿用上游更新入口，试用时不要安装上游版本更新，以免覆盖精简版。

手动检查：

1. 在浏览器和文本编辑器中拖选文字、双击选词，确认只显示悬浮图标。
2. 点击图标，确认选中文字被翻译；不点击则不应取词或请求翻译。
3. 选择新的文字，确认翻译内容更新；点击其他位置，确认图标隐藏。
4. 按 `Alt + S` 截图，确认 OCR 结果进入原有翻译流程。
5. 检查主窗口、OCR 窗口、设置页和快捷键列表，确认没有生词本或朗读入口。
6. 使用已有配置启动，确认原有翻译、OCR 引擎和划词偏好保持可用。
